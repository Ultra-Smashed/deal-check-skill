# Deal-Check in ChatGPT

Der Skill ist für Claude gebaut. In ChatGPT bekommst du dieselben vier Module als Projekt mit Anweisungen. Die Anweisungen stehen in [`anweisungen.txt`](anweisungen.txt).

## Als Projekt (geht in jedem Tarif)

1. In ChatGPT links in der Seitenleiste **Neues Projekt** anlegen, Name: **Deal-Check**.
2. Im Projekt oben auf das Zahnrad bzw. **Anweisungen** klicken.
3. Den kompletten Inhalt von [`anweisungen.txt`](anweisungen.txt) einfügen und speichern.
4. Im Projekt einen neuen Chat öffnen und einen Produktlink oder Screenshot schicken: „Lohnt sich dieser Deal?“

Die Websuche muss an sein, sonst kann ChatGPT keine Preise prüfen.

## Als eigener GPT (zum Teilen)

1. [chatgpt.com/gpts/editor](https://chatgpt.com/gpts/editor) öffnen, auf **Konfigurieren** wechseln.
2. **Name:** Deal-Check
3. **Beschreibung:** Prüft Black-Friday-Angebote: Preisverlauf, echte Ersparnis, Shop-Vergleich und ein klares Urteil, kaufen, warten oder lassen.
4. **Anweisungen:** Inhalt von [`anweisungen.txt`](anweisungen.txt).
5. **Gesprächseinstiege:**
   - Lohnt sich dieser Deal? (Link einfügen)
   - Prüf diesen Screenshot von einem Angebot.
   - Richte mir einen Preiswächter für meine Wunschliste ein.
   - Brauche ich das überhaupt?
6. **Fähigkeiten:** Websuche an, Code-Interpreter an, Bildgenerierung aus.
7. **Erstellen**, Sichtbarkeit: **Jeder mit dem Link**.

In eigenen GPTs gehen keine geplanten Aufgaben. Für den Preiswächter gibt dir der GPT den fertigen Prompt, den du in einem normalen Chat als geplante Aufgabe anlegst.

## Was in ChatGPT anders ist

- **Geplante Aufgaben** gibt es in ChatGPT in allen Tarifen, kostenlos bis zu drei aktive. Sie laufen höchstens einmal pro Stunde.
- **Gmail:** Für Postfach-Deals Gmail unter **Einstellungen → Apps** verbinden. Danach durchsucht ChatGPT deine Werbemails direkt.
